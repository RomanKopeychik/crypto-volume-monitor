# Crypto Volume Monitor

Учебный проект для практики Airflow, PostgreSQL и Superset.

Каждые 5 минут данные об объёмах торгов BTCUSDT, ETHUSDT
и SOLUSDT загружаются из Binance API в PostgreSQL.
В Superset построен дашборд за последнюю загруженную пятиминутную свечу и последние 24 часа.

## Как работает

Binance API → Airflow → PostgreSQL → Superset

DAG состоит из двух задач: получение данных и запись в базу.
Загружаются завершённые пятиминутные свечи.
Добавлены проверки данных, логирование и повторные попытки.
Повторная запись обновляет данные без создания дублей.

Airflow и Superset запускались локально в Docker.

## Содержимое

- `dags/` — код DAG.
- `sql/` — создание таблицы и запросы для графиков.
- `screenshots/` — дашборд и успешное выполнение DAG.

## Запуск

Для проекта нужны Airflow 3, PostgreSQL и Superset.

1. Создать таблицу в базе PostgreSQL,
   выполнив 'sql/create_tables.sql'.
2. В Airflow создать подключение типа Postgres с ID 'bi_db':
   указать хост, порт, название аналитической базы,
   пользователя и пароль.
3. Поместить 'crypto_volume.py' в папку dags используемой
   установки Airflow.
4. Включить DAG crypto_volume и дождаться запуска по расписанию.
5. Для дашборда подключить аналитическую базу к Superset
   и настроить графики по 'sql/dashboard_queries.sql'.
